# Allowed terms

Gate G10 checks every word on an English page. A word passes only if it is in the British English dictionary the gate uses, or in this table. Anything else fails the build and is listed by page and line. That catches Hinglish, and typos too.

Changes to this file need Satya's approval, like rules/contacts.md.

## Rules

- **Names:** schemes, portals, apps, agencies, places and festivals, used only as names. "Aadhaar" is allowed; a Hindi word used as an ordinary word is not.
- **Acronyms:** used in their official form. Write each one in full the first time it appears on a page, unless readers know it better as the acronym (UPI, OTP, SIM).
- **Indian English words:** only the ones below with status `approved`.
- **Script:** English pages carry only English letters, digits, punctuation and ₹. No Devanagari or Odia characters, not even inside a name.
- **If the final project name is a Hindi or Odia phrase,** it goes here as a name.
